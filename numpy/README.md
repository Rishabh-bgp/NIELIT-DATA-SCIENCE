# NumPy Tutorials

This folder contains four progressive Jupyter notebooks covering the fundamentals of **NumPy**, the foundational numerical computing library for Python data science.

## Notebooks

| File | Focus |
|------|-------|
| `NumPy_Tutorial_1.ipynb` | Performance comparison (Python lists vs NumPy arrays) and basic introduction |
| `NumPy_Tutorial_2.ipynb` | Array creation, shapes, dtypes, and basic operations |
| `NumPy_Tutorial_3.ipynb` | Indexing, slicing, boolean masks, and reshaping |
| `NumPy_Tutorial_4.ipynb` | Sorting utilities (`argsort`, `argmin`, `argmax`), linked data sorting, and top-N selection |

## Why Start Here?

NumPy provides the fast array backbone that Pandas and most machine learning libraries are built upon. Understanding vectorized operations and broadcasting early will make later material significantly easier.
