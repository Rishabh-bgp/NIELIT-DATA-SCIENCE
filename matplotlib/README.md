# Matplotlib Tutorials

This folder contains a comprehensive Jupyter notebook covering **Matplotlib**, the foundational plotting library in the Python data science stack.

## Notebook

| File | Focus |
|------|-------|
| `Matplotlib.ipynb` | Line, bar, scatter, histogram plots; customization; subplots; styling; annotations; saving figures |

## Why Matplotlib?

Visualization is how you explore data and communicate results. Matplotlib provides the building blocks used by higher-level libraries such as Seaborn and the plotting backends of Pandas.

## Prerequisites

- Comfort with NumPy and Pandas (recommended but not strictly required for basic plots)
- Repository environment set up

## Tips

- Experiment with different plot types and style parameters.
- Try combining Pandas DataFrames with Matplotlib axes for labeled data.
- Clear outputs before committing if you modify the notebook.
