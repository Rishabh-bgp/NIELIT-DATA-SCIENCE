# Pandas Tutorials

This folder contains four progressive Jupyter notebooks plus a standalone script covering **Pandas**, the primary library for tabular data manipulation in Python.

## Notebooks

| File | Focus |
|------|-------|
| `Pandas_Tutorial_1.ipynb` | Series and DataFrame creation, basic attributes |
| `Pandas_Tutorial_2.ipynb` | Data inspection and cleaning (missing values) |
| `Pandas_Tutorial_3.ipynb` | Selection (`.loc` / `.iloc`), boolean indexing, transformations |
| `Pandas_Tutorial_4.ipynb` | Aggregation (`groupby`), pivoting, and joining |

## Script

- `pandas_manipulation_demo.py` — Self-contained demonstration of slicing and column-addition techniques. Run with:
  ```bash
  python pandas_manipulation_demo.py
  ```

## Why Pandas?

Pandas builds on NumPy and adds labels, heterogeneous data types, and powerful data-wrangling tools essential for real-world data analysis.
